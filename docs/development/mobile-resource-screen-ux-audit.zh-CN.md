# 资源页 UI/UX 审计：Mobile vs Web

## 一、当前 Mobile 资源页能力

| 功能 | 实现情况 |
|------|----------|
| 库选择（全部文件 / 指定知识库） | ✅ |
| 文件夹面包屑导航 | ✅ |
| 分类 Tab（全部 / 图片 / 文档 / 其他） | ✅ |
| 列表 / 网格视图切换 | ✅ |
| 搜索 | ✅ |
| 排序（时间 / 名称 / 大小） | ✅ |
| 多选模式（批量删除、批量移动） | ✅ |
| 新建文件夹（仅库内） | ✅ |
| 移动到文件夹 | ✅ |
| 上传（相册 / 文档选择器） | ✅ |
| 删除 | ✅ |
| 预览（图片 / PDF / 文本 / Markdown） | ✅ |
| 下拉刷新、加载更多 | ✅ |

---

## 二、与 Web 的差异

| 功能 | Web | Mobile |
|------|-----|--------|
| 文档编辑 | FileEditor、PageEditor | ❌ 仅预览 |
| Chunk 信息 | ChunksBadge、ChunkDrawer、批量分块 | ❌ 无 |
| 拖拽上传 | DragUploadZone | ❌ 无（移动端无拖拽） |
| 批量操作 | 移除出库、批量分块、删除 | 删除、移动 |
| 右键/长按菜单 | 丰富下拉菜单 | 长按 → Alert（删除 / 移动） |

## 三、UX 可优化点

### 3.1 高优先级

#### 1. Header 信息过载

**现状**：ScreenHeader 内同时包含：
- 库选择器
- 面包屑（进入文件夹时）
- 搜索框
- 分类 Tab + 排序按钮

**问题**：内容过多，首屏信息密度高，小屏设备易拥挤；滚动时 Header 可能占据大量空间。

**建议**：
- 库选择器与面包屑合并为一行，或库选择器可折叠
- 搜索框可改为点击展开（类似 ChatList）
- 分类 Tab 与排序可考虑合并为「筛选」入口

#### 2. 新建文件夹入口隐蔽

**现状**：需点击 FAB → AttachmentSheet →「新建文件夹」，且仅在已选库内显示。

**问题**：用户不易发现；在「全部文件」模式下无法新建文件夹（符合逻辑，但缺少引导）。

**建议**：
- 在库选择后、空文件夹内，EmptyState 中突出「新建文件夹」按钮
- 在库内时，FAB 长按或二级菜单中提供「新建文件夹」快捷入口

#### 3. 长按操作单一

**现状**：
- 文件：长按 → Alert（删除 / 移动到文件夹）
- 文件夹：长按 → 直接删除确认

**问题**：缺少重命名、复制、分享等；与 Web 的右键菜单能力差距大。

**建议**：
- 长按改为底部 ActionSheet，包含：预览、移动、重命名、分享、删除
- 文件夹增加：重命名、移动

#### 4. 选择模式进入路径长

**现状**：需点击 Header「选择」→ 再逐个勾选。

**建议**：
- 长按文件/文件夹时，可提供「进入多选」选项，或长按直接进入多选并选中当前项
- 多选时显示已选数量，便于快速确认

### 3.2 中优先级

#### 5. 排序菜单过重

**现状**：全屏底部 Modal，占满下半屏。

**建议**：改为下拉菜单或 Popover，减少打断感。

#### 6. 空状态引导不足

**现状**：EmptyState 有标题和描述，但无明确 CTA。

**建议**：
- 根目录空状态：突出「上传文件」按钮
- 库内空文件夹：突出「上传」和「新建文件夹」按钮

#### 7. Grid 模式信息缺失

**现状**：Grid 仅显示缩略图 + 文件名，无大小、日期。

**建议**：可考虑在卡片底部显示日期或大小（可选，避免过于拥挤）。

#### 8. 预览后无编辑

**现状**：Markdown/文本可预览，但无法编辑。

**建议**：若后续支持文档编辑，可在预览页增加「编辑」入口。

### 3.3 低优先级

#### 9. FAB 可能遮挡内容

**现状**：右下角固定 FAB，列表底部可能被遮挡。

**建议**：列表 `paddingBottom` 已考虑 FAB，可确认最后一屏是否完全可见；或 FAB 在滚动时自动收起。

#### 10. 面包屑过长

**现状**：深层级时面包屑横向滚动。

**建议**：可考虑省略中间层级，仅保留「根 / ... / 当前」；或保持现状，已可横向滚动。

#### 11. 暗色模式

**建议**：确认与 App 主题一致，无遗漏。

## 四、功能对齐建议（可选）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 文档/Page 编辑 | 高 | Web 核心能力，Mobile 可后续支持 |
| Chunk 信息展示 | 中 | 可展示 chunk 数、分块状态，不一定要 ChunkDrawer |
| 批量分块 | 低 | 依赖 Chunk 能力 |
| 重命名 | 高 | 文件/文件夹重命名，实现成本低 |
| 分享 | 中 | 部分已有 Share，可统一入口 |
