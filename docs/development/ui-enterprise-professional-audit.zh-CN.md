# UI 企业感与专业感升级方案

> **日期**：2026-03-18\
> **范围**：`apps/mobile` 全量 UI\
> **目标**：在不增减功能的前提下，提升企业感、专业感，同时保持人性化\
> **原则**：零功能变更，仅调整视觉、动效、文案与交互质感

---

## 一、现状诊断

### 1.1 当前气质

| 维度       | 现状                                          | 企业感缺口                       |
| ---------- | --------------------------------------------- | -------------------------------- |
| **色彩**   | 高饱和主色（#007aff）、多色系（蓝 / 紫 / 绿） | 企业偏好更克制的色相、更低饱和度 |
| **字体**   | font-extrabold 广泛使用、字号跨度大           | 层级过重、缺乏统一字重阶梯       |
| **圆角**   | rounded-2xl/3xl 为主                          | 略偏「圆润消费风」               |
| **动效**   | MeTab 旋转、AnimatedTabLabel、FadeInDown 逐项 | 偏活泼，企业场景宜更克制         |
| **空状态** | 大 emoji（📭 48px）为主视觉                   | 偏轻松，企业场景宜更中性         |
| **文案**   | 口语化、简短                                  | 可更结构化、可预期               |
| **Blur**   | ScreenHeader 全 BlurView                      | 偏消费端，企业常用扁平 header    |

### 1.2 已有优势（需保留）

- 主题系统（light/dark + 色系）完整
- 语义色（success/danger/warning）清晰
- SettingsLayout、SectionBlock、DangerZoneSection 结构清晰
- PressableScale 等交互反馈细腻
- 无障碍与 i18n 基础良好

---

## 二、升级策略总览

**核心思路**：通过「克制」「秩序」「可预期」三个关键词，在不改功能的前提下重塑视觉与交互质感。

| 策略   | 企业感                   | 专业感                   | 人性化               |
| ------ | ------------------------ | ------------------------ | -------------------- |
| 克制   | 降低饱和度、减少动效强度 | 统一字重、减少视觉噪音   | 保留必要反馈、不冰冷 |
| 秩序   | 统一间距、对齐、层级     | 明确区块、标题、列表规范 | 信息分组清晰、易扫读 |
| 可预期 | 交互模式一致             | 文案结构化、可复用       | 语气温和、不居高临下 |

---

## 三、具体方案

### 3.1 色彩克制化

**目标**：主色更沉稳，辅助色更中性。

| 调整项     | 现状                                           | 建议                                                  | 影响范围                   |
| ---------- | ---------------------------------------------- | ----------------------------------------------------- | -------------------------- |
| 主色饱和度 | blue #007aff                                   | 略降为 #0066d6 或保持，但增加 `primaryMuted` 使用场景 | 按钮、链接、强调           |
| 企业色系   | 仅 blue/violet/green                           | 新增 `slate` 色系（中性灰蓝）作为「企业默认」         | palettes.ts、Settings 选项 |
| 背景层次   | 大量 `bg-foreground/5`、`bg-foreground/[0.02]` | 统一为 2–3 档：surface /surfaceElevated/fillTertiary  | 全局                       |
| 边框       | 部分透明、部分无                               | 统一 `borderSubtle`，弱化分割线                       | 卡片、区块                 |

**人性化保留**：不改为纯灰，保留色系选择；成功 / 错误仍用语义色，保持可读性。

---

### 3.2 字体层级规范化

**目标**：建立清晰、可复用的字重与字号阶梯。

| 层级    | 用途         | 现状                    | 建议                                 |
| ------- | ------------ | ----------------------- | ------------------------------------ |
| H1      | 主屏标题     | 22px extrabold          | 22px semibold（600）                 |
| H2      | 区块标题     | 11px uppercase semibold | 12px uppercase medium，tracking 略减 |
| H3      | 列表项主文字 | 15–15.5px medium        | 统一 15px medium                     |
| Body    | 正文         | 14–16px 混用            | 14px regular，15px medium 用于强调   |
| Caption | 副标题、描述 | 12–12.5px               | 统一 12px                            |

**实施**：

- 将 `font-extrabold` 改为 `font-semibold`（ScreenHeader、SectionBlock 等）
- 新增 `tokens.typography` 的 `heading`、`body`、`caption` 规范
- 减少 `font-bold` 使用，改为 `font-semibold` 或 `font-medium`

**人性化保留**：不改为等宽或极细体，保持可读性；行高适度，不压缩。

---

### 3.3 圆角与间距秩序化

**目标**：统一圆角档位，建立清晰间距节奏。

| 元素       | 现状                        | 建议                                          |
| ---------- | --------------------------- | --------------------------------------------- |
| 主按钮     | rounded-2xl                 | 保持 rounded-2xl，或改为 rounded-xl（略收敛） |
| 卡片       | rounded-2xl                 | 统一 rounded-xl                               |
| 小标签     | rounded-lg /rounded-xl 混用 | 统一 rounded-lg                               |
| 区块标题   | 无统一                      | 使用 `mb-2` + `px-2` 对齐                     |
| 列表项间距 | mb-2 /mb-3 混用             | 统一 mb-2（紧凑）或 mb-3（宽松）              |

**实施**：在 `tokens.ts` 中明确 `radius.card`、`radius.button` 等。

---

### 3.4 动效克制化

**目标**：保留必要反馈，减少「表演性」动效。

| 调整项           | 现状                         | 建议                                  |
| ---------------- | ---------------------------- | ------------------------------------- |
| MeTab 旋转       | 360° 旋转 + scale            | 仅保留 scale 或移除（企业场景少用）   |
| AnimatedTabLabel | opacity + scale + translateY | 仅 opacity 变化，或缩短 duration      |
| FadeInDown 逐项  | 多屏 delay 50–300ms          | 首屏保留，列表项取消或统一 delay 80ms |
| 按钮按压         | PressableScale 0.97          | 保持，或改为 0.98（更 subtle）        |

**人性化保留**：保留 haptics、PressableScale 等触觉反馈；加载态、成功态仍用轻量动画。

---

### 3.5 空状态中性化

**目标**：减少 emoji 主导，增加信息密度与专业感。

| 调整项          | 现状         | 建议                                             |
| --------------- | ------------ | ------------------------------------------------ |
| EmptyState icon | 48px emoji   | 可选：lucide 图标 + 小尺寸，或 emoji 缩小至 32px |
| 空状态文案      | 简短、口语化 | 增加「下一步建议」或「可执行操作」的短句         |
| 插画风格        | 无           | 可选：极简几何插画（非必需）                     |

**人性化保留**：不改为纯文字，保留视觉锚点；语气仍友好，不冷冰冰。

---

### 3.6 Header 与导航扁平化

**目标**：BlurView 可选化，提供「扁平」模式。

| 调整项       | 现状           | 建议                                  |                                                 |
| ------------ | -------------- | ------------------------------------- | ----------------------------------------------- |
| ScreenHeader | 全 BlurView    | 增加 \`headerStyle: 'flat'            | 'blur'`，默认 flat 时用 `bg-background\` + 细线 |
| TabBar       | 无边框、shadow | 保持，或增加 1px 顶部分割线（更清晰） |                                                 |

**人性化保留**：保留 blur 可选，供偏好「玻璃质感」的用户使用。

---

### 3.7 文案与微文案专业化

**目标**：结构化、可预期、不居高临下。

| 场景   | 原则            | 示例                                            |
| ------ | --------------- | ----------------------------------------------- |
| 按钮   | 动词优先、简短  | 「保存」→「保存」；「删除」→「删除会话」        |
| 错误   | 原因 + 建议     | 「连接失败」→「无法连接服务器，请检查网络设置」 |
| 空状态 | 状态 + 建议     | 「暂无会话」→「暂无会话，点击下方开始新对话」   |
| 设置项 | 标签 + 说明分离 | 副标题说明用途，不堆砌                          |

**人性化保留**：避免「您」「请」过度；保持第二人称、语气温和。

---

### 3.8 组件一致性

**目标**：统一按钮、卡片、输入框的视觉语言。

| 组件   | 现状                     | 建议                                    |
| ------ | ------------------------ | --------------------------------------- |
| 主按钮 | rounded-2xl py-4         | 统一高度、圆角，使用 `PressableScale`   |
| 次按钮 | 多种样式                 | 统一 outline 或 subtle 背景             |
| 卡片   | SurfaceCard / 自定义混用 | 统一 SurfaceCard 或明确「卡片变体」规范 |
| 输入框 | 多种背景                 | 统一 `inputBg`、`borderSubtle`          |

---

## 四、实施优先级

### P0（高影响、低成本）

1. **字体层级**：`font-extrabold` → `font-semibold`（ScreenHeader、SectionBlock 等）
2. **区块标题**：统一 `text-[12px]`、`tracking-widest` 略减
3. **空状态**：emoji 缩小至 32px，或增加 lucide 图标选项

### P1（中影响、中成本）

4. **新增 slate 色系**：企业默认色
5. **动效克制**：MeTab 旋转简化、FadeInDown delay 统一
6. **圆角统一**：卡片 rounded-2xl → rounded-xl

### P2（体验提升、需设计）

7. **Header 扁平模式**：可选 flat/blur
8. **文案微调**：错误 / 空状态文案结构化
9. **间距规范**：mb-2/mb-3 统一

---

## 五、设计 Token 补充建议

在 `tokens.ts` 中新增或明确：

```ts
// 企业感升级用
enterprise: {
  headerStyle: 'flat' | 'blur' | 'auto',
  buttonRadius: 12,  // rounded-xl
  cardRadius: 12,
  animationDuration: { fast: 150, normal: 250, slow: 400 },
  fontWeight: { heading: '600', body: '500', caption: '400' },
}
```

## 六、人性化守护清单

升级过程中需持续确保：

- [ ] 色彩对比度满足 WCAG AA（正文 4.5:1）
- [ ] 触觉反馈（haptics）保留
- [ ] 加载态、成功态有明确反馈
- [ ] 错误文案不推责、不恐吓
- [ ] 空状态有「下一步」建议
- [ ] 色系选择保留（用户可个性化）
- [ ] 深色模式体验不降级

---

## 七、结论

通过**色彩克制**、**字体层级**、**动效收敛**、**空状态中性化**、**文案结构化**五条主线，可在不增减功能的前提下，显著提升企业感与专业感。人性化通过保留触觉反馈、温和语气、可读性及个性化选项来维持。

建议按 P0 → P1 → P2 分阶段实施，每阶段完成后做灰度或 A/B 测试，收集用户反馈后再推进下一阶段。
