# 命令菜单

命令菜单是 LobeHub 的快捷操作中心。按下 `⌘ + K`（Mac）或 `Ctrl + K`（Windows/Linux），搜索浮层会出现在屏幕中央。输入几个关键词即可找到智能体、话题、设置或操作 —— 无需逐层点击菜单或侧边栏。这是浏览 LobeHub 最快的方式。

**模糊搜索** — 无需输入完整名称。「编程」或「python」都能匹配「Python 编程智能体」。频繁切换智能体时，命令菜单比在侧边栏中查找快得多。

## 打开命令菜单

- **macOS：** `Cmd + K`
- **Windows/Linux：** `Ctrl + K`

菜单会以浮层形式出现在屏幕中央。

## 可以搜索什么

| 类型          | 示例                         |
| ----------- | -------------------------- |
| **智能体**     | 输入智能体名称切换会话或开始新对话          |
| **话题**      | 输入话题关键词跳转到历史对话             |
| **板块**      | 「设置」「文稿」「资源」—— 直接跳转到对应板块   |
| **技能与 MCP** | 搜索插件和 MCP 服务器              |
| **操作**      | 「创建智能体」「创建群组」—— 无需进入菜单即可执行 |

**键盘导航：** 用 `↑` 和 `↓` 在结果间移动，`Enter` 执行，`Esc` 关闭。输入消息时，`Tab` 可在结果类别间切换。

## 向智能体提问

要与指定智能体开始对话：

1. 按 `Cmd + K` / `Ctrl + K` 打开命令菜单
2. 输入你的消息或话题
3. 按 `Tab` 切换到智能体选择器
4. 选择智能体并按 `Enter` —— 对话立即开始

**新建：** 选择「创建智能体」或「创建群组」，按 `Enter` 即可创建，无需离开菜单。

## 快捷导航

选择「文稿」「资源」等板块，按 `Enter` 即可跳转。无需滚动侧边栏，无需额外点击。

## 搜索内容

输入关键词可搜索：

- **历史消息** — 按内容查找对话
- **智能体** — 按名称或描述切换
- **MCP 插件** — 查找并访问已安装的工具

结果会分类显示，方便快速识别并选择正确项。

## 使用场景

**任务中途切换智能体** — `Cmd + K` → 输入智能体名 → 回车。比在侧边栏点击更快。

**恢复之前的对话** — `Cmd + K` → 输入话题中的关键词 → 回车。直接跳转到该话题。

**不打断流程创建新智能体** — `Cmd + K` → 「创建智能体」→ 回车。无需找到创建按钮。

**快速进入设置** — `Cmd + K` → 「设置」→ 回车。一个快捷键替代头像 → 菜单 → 设置。

## 使用技巧

- **打开后直接输入** — 菜单打开后即可输入，无需点击搜索框。
- **用 Tab 切换上下文** — 输入消息后，Tab 可切换到选择智能体或操作，已输入内容不会丢失。
- **Esc 取消** — 随时按 Esc 关闭菜单，不执行任何操作。
